AI Proof Filter Generator

Discription

We created a code using HTML and Python that will take any image uploaded, then run it through a code that will apply a special filter that will make it relatively safer to upload online. Why? Because many artists who upload their art online are trying to get a profit out of it, but instead, other people are using A.I to take the art for their own by using it to train the A.I so it can create images for them, or just to take the art completely. For example, there is an artist named Richard Prince who made over $100, 000 by selling printed screenshots of other people’s Instagram posts. The artist never asked for permission, as confirmed by an Instagram user whose post he used to make profit. The filter is created by using the randomness of the chaos theory to generate fractals. We chose to do fractals as redemtion for our really bad math fair in grade 5. We used something called the Mandelbrot equation - the same equation used to generate a really popular fractal - to create noise patterns that will help guide the generation of the lines that will be used as our filter.
